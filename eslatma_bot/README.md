# Шахсий эслатма котиби (Telegram бот, кўп фойдаланувчили)

Ҳар ким ботга кириб, ўз эслатмаларини (тўлов, ойлик, солиқ, учрашув) қўшади. Бот вақтида эслатади, бажарилмаса қайта-қайта эслатади.

## Ишга тушириш
1. @BotFather → `/newbot` → токен.
2. `export TELEGRAM_BOT_TOKEN="токен"` · `python3 bot.py` (Python 3.10+, қўшимча кутубхонасиз).
3. Тест: `python3 -I -c "import test_bot,sys;[getattr(test_bot,n)() for n in dir(test_bot) if n.startswith('test_')]"`
База: `data.db` (SQLite, `DB_PATH` билан ўзгартириш мумкин; файл рухсати 600).

## Фойдаланувчи учун
- ➕ Янги эслатма: шаблон (аренда, ойлик, солиқ, WiFi, CRM, коммунал) ёки ўз номи → тез-тезлиги (ҳар ой/ҳафта/бир марта) → сана → соат → олдиндан огоҳлантириш → сумма.
- Эслатма келганда 2 тугма: **✅ Бажарилди** ва **⏰ Кейинрок** (1/2/3/6/12 соат, эртага, ёки ўзи рақам киритади).
- Жавоб бермаса — ҳар N соатда (стандарт 3) такрорлайди; тунда 22:00–07:00 хабар юбормайди; 8 кундан ортиқ ўтганини ёпади.
- /privacy · /deleteme (ҳамма маълумотни ўчириш) · /cancel

## Хавфсизлик
- Ҳар бир SQL сўров `user_id` бўйича чекланган; тугма босилганда вазифа эгалиги текширилади (бошқанинг ID сини юборса ҳам ҳеч нарса бўлмайди — тестланган).
- Фақат шахсий чат; гуруҳлар эътиборсиз. Параметрланган SQL, HTML escape, киритиш узунлиги чекланган, спамга қарши лимит (10 сек/20 хабар), фойдаланувчига 100 эслатма лимити.
- Токен фақат env да. Лог хабар матнини ёзмайди.
- ⚠️ Чекловлар: ботни ишга туширган одам (сиз) серверда `data.db` ни техник жиҳатдан ўқий олади. Шифрлаш керак бўлса — алоҳида режа (харита 8-бўлим).
