# Тўлов эслатма боти (Молия директори учун)

Аренда, WiFi, CRM, солиқ, ходимлар ойлиги ва бошқа тўловларни Telegram орқали олдиндан эслатади.

## Ишга тушириш (5 дақиқа)
1. Telegram да @BotFather → `/newbot` → **токен** олинг.
2. `export TELEGRAM_BOT_TOKEN="токен"` ва `python3 bot.py`
3. Ботга `/start` ёзинг — эслатмалар шу чатга келади.
4. `payments.json` да санлар ва суммаларни ўзингизникига алмаштиринг.

## Командалар
`/soon` яқин 14 кун · `/list` барча тўловлар · `/done <код>` тўланди (эслатма тўхтайди)

## payments.json
`freq`: monthly / quarterly / yearly / once · `day` сана · `remind_before` неча кун олдин ([3,1,0]) · `amount`, `note` ихтиёрий.
Янги тўлов қўшиш = рўйхатга битта қатор қўшиш.

## Серверда доим ишлаши
Бот доим ишлаб туриши керак (VPS, Railway, Render ёки уй компьютери): `nohup python3 bot.py &`
Ёки systemd/Docker. Ҳолат `state.json` да сақланади.

## Кейинги агентлар (тизимлаштириш режаси)
Бу бот асос. Кейин шу структурага: ойлик/дебитор-кредитор назорати, ҳисобот йиғувчи, ҳужжат (счёт-фактура) текширувчи агентлар қўшилади.
