# Шахсий эслатма котиби (Telegram бот, кўп фойдаланувчили, UZ/РУС)

Ҳар ким ботга кириб, ўз эслатмаларини қўшади. Бот вақтида эслатади, бажарилмаса қайта эслатади.

## Ишга тушириш
Windows: `ishga_tushir.bat` ни икки марта босинг, токенни киритинг. Бошқа тизим: `TELEGRAM_BOT_TOKEN=... python3 bot.py` (Python 3.10+, қўшимча кутубхонасиз).
Тест: `python3 -I -c "import test_bot as T;[getattr(T,n)() for n in dir(T) if n.startswith('test_')]"` (14 та)

## Фойдаланувчи учун
- Биринчи кириш: тил танлаш (🇺🇿 UZB / 🇷🇺 РУС). Кейин ҳам ⚙️ Созламалардан ўзгартириш мумкин.
- ➕ Янги: нима эслатиш → қачон (бир марта аниқ кун / ҳар ой / ҳар ҳафта / ҳар куни) → сана (календарь ёки 1–30 тўр) → соатлар (бир нечтасини танлаш мумкин) → олдиндан огоҳлантириш → сумма/изоҳ. Ҳамма саволлар БИТТА хабарда алмашиб туради, чат тоза қолади.
- Эслатма: 🚨 хабар + «✅ Бажарилди» / «⏰ Кейинрок» (1/2/3/6/12 соат, эртага, ёки ўзи киритади).
- Танланган вақтларда эслатади; охирги вақтдан кейин жавоб бўлмаса ҳар N соатда (созланади, ўчирса бўлади) такрорлайди; тунда (22–07) такрор юбормайди.
- Овозни ўзгартириш: Telegram чат созламаси (⚙️ → 🔔 тугмасида йўриқнома).
- /privacy · /deleteme · /cancel

## Хавфсизлик
Ҳар SQL сўров `user_id` бўйича чекланган, тугмада эгалик текширилади (бошқа одамнинг ID сини юборса ҳам иш қилмайди — тестланган). Фақат шахсий чат; параметрланган SQL; HTML escape; киритиш узунлиги/лимит (100 эслатма, 40 хабар/10 сония); токен фақат env. ⚠️ Бот эгаси серверда `data.db` ни техник ўқий олади.

## Муҳим: пастки меню
Пастки меню ўчирилмайдиган алоҳида «🏠 Асосий меню» хабарига боғланган (Telegram ташувчи хабар ўчса менюни ҳам олиб ташлайди). Уни ўчирманг; йўқолса `/start` қайта юборади.
